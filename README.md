# Proyecto-Socioformativo
Implementar y demostrar el DNS y la infraestructura web de la organización elegida.
INSTRUCCIONES 

• Elegir la organización, levantar sus necesidades y diseñar el plan de nombres (zona interna .internal y zona pública), la red y los servicios.
• Implementar el DNS: BIND9 primario y secundario con vistas interna/externa, DNSSEC con dnssec-policy (validado con delv), transferencia con TSIG, resolutor con DNS sobre TLS y RPZ, y zona pública en DNSControl con validación automática. 
• Integrar los servicios por nombre: sitio web con HTTPS, SSH endurecido y correo con MX, SPF, DKIM y DMARC.
• Aplicar seguridad básica (firewall ufw, fail2ban, actualizaciones), monitoreo del DNS y de los servicios, reportes de registros (GoAccess) y respaldos de configuración.
• Entregar el manual de operación, el informe de pruebas y la bitácora de IA; defender con demostración en vivo de 15 minutos.
• Informe técnico final + consolidado de bitacora IA de todo con formato APA v7, también deben poner el enlace a su repositorio Github + presentación de Actividad en .pptx o html o pdf
